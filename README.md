# GateSim

A logic gate simulator built with React.

Link to deployed website : https://arpit-shinde.github.io/GateSim/

## Features

- Dynamic gate creation
- Dynamic gate connections
- Recursive graph evaluation
- Live simulation
- Click to Connect 
- Wire drawing (beizer curve)
- Drag-and-drop gate placement
- wire deletion
- gate deletion
- Better SVG for gates
- UI including menu, options,etc
- Sequential Circuits
- Clock support
- Flip-flops
- Supports:
  - AND
  - OR
  - NOT
  - XOR
  - NAND
  - NOR
  - XNOR
