# Testing

## Primitive Correctness
The following primitive gates were tested in their input domains and the observed outputs matched with expected outputs: 
AND, OR, NOT, NAND, NOR, XOR, XNOR, AND3, OR3, NAND3, NOR3, XOR3, XNOR3, AND4, OR4, NAND4, NOR4, XOR4, XNOR4.

## Combinational Correctness
The following combinational circuits were built and tested:
- Half Adder
- Full Adder
- 2-1 Multiplexer

## Sequential Correctness
The following sequential circuits were built and tested:
- SR Latch
- Master Slave JK Flip Flop 

## Hierarchical Correctness
The following circuits were encapsulated as custom component and tested:
- 1-bit Full Adder
- Master Slave JK Flip Flop

The following circuits were built using custom components and tested:
- 4-bit Full Adder
- 4-bit Ripple Counter
- 1-bit ALU
- 4-bit ALU
- 4-bit Program Counter
